1. Balancing_Run: off-by-one, out-of-bounds read
for (i = 0; i <= NUM_CELLS; i++) reads cell_mv[16] on a 16-element array. Use <.

2. Balancing_Run: vmin initialised to 0
cell_mv[i] < vmin can never be true, so vmin stays 0 and every cell above 15 mV is flagged for balancing. Initialise to 0xFFFF.

3. Balancing_Run: bal_mask is never cleared
It only ever gets |=, so once a cell is marked for balancing it stays that way forever, even after it has converged. Set bal_mask = 0 at the start of each run (or build a local mask and write it at the end).

4. CAN_TxPackStatus: CRC computed over its own byte
Crc8(data, 8) includes data[7], which is uninitialised at that point, so the CRC is non-deterministic. It should be Crc8(data, 7). Also initialise the array (= {0}).

5. AFE_SPI_IRQHandler: blocking delay in an ISR
Delay_ms(2) inside an interrupt stalls the system and can deadlock if the delay depends on SysTick at the same or lower priority. Use a hardware timer or a state flag that the main loop or a timer callback acts on to start the next conversion.

Serious / design issues

6. pack_mv is uint16_t
A 16S pack at 4.2 V/cell reaches 67.2 V, which overflows 65,535 mV. This is fine for LFP (about 58.4 V max) but wrong for NMC/NCA. Use uint32_t for the pack voltage, and saturate on the way into the CAN frame.

7. Shared data between ISR and main loop

cell_mv is written in the ISR and read in Balancing_Run, but it isn't volatile, so the compiler may cache reads.
The main loop can see a half-updated frame (some cells new, some old), which gives a wrong vmin. Use a shadow buffer filled by the ISR, then swap it or set a "frame ready" flag once all 16 cells are read.
On an 8-bit MCU, even a single uint16_t read isn't atomic.

8. No validity or fault checks

No check for SPI read errors, AFE CRC/PEC, or stale data. If the AFE stops responding, balancing runs on old values.
idx can't resynchronise if an interrupt is missed or the AFE restarts. Cell N's data could end up in slot N+1.
Return values of AFE_WriteBalMask and CAN_Send are ignored.

9. Balancing logic is missing safety conditions

No hysteresis (start at 15 mV, stop at, say, 5 mV), so cells near the threshold will chatter.
No minimum cell voltage gate (balancing a deeply discharged cell is bad).
No temperature or current-state gating, and no pause during measurement. Balancing current causes IR-drop error in the readings, so most designs stop balancing before a conversion.
No periodic mask refresh or AFE watchdog handling. Many AFEs drop the mask if it isn't rewritten.
